# Intelligent Network Fault Diagnosis

A scientific, reproducible virtual networking laboratory for fault detection, localization, and remediation.

## Scope

- Real traffic and virtual Ethernet fault experiments (Linux namespaces / Mininet in WSL2 or Ubuntu)
- Wi-Fi 2.4 GHz / 5 GHz: ns-3 experiments (planned)
- Fiber and microwave: validated mathematical link models coupled to network impairments (planned)
- Python API, React interface, tests, structured telemetry and reproducible fault scenarios

**Scientific integrity:** Synthetic measurements are always labeled; physical-layer models are not represented as real hardware measurements. No remediation runs against a production network.

This repository is being developed incrementally. See upcoming files for reproducible local setup and experiments.
